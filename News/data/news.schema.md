# 动态数据格式说明（News/data/news.json）

页面 `News/news.html` 会在加载时读取本文件并渲染。**新增或修改动态时，只需编辑 `news.json`，不要再改动 `news.html`。**

## 文件整体结构

```json
{
  "updated": "2026-11-26",
  "items": [
    { /* 条目 1 */ },
    { /* 条目 2 */ }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `updated` | 否 | 数据最后更新时间，任意字符串，仅作记录，目前页面不展示。 |
| `items` | 是 | 新闻条目数组。顺序无所谓，页面会按 `date` 从新到旧自动排序。 |

## 单个条目（items 中的对象）

| 字段 | 必填 | 类型 | 说明 |
| --- | --- | --- | --- |
| `date` | 是 | 字符串 | 日期，格式 `YYYY-MM-DD`，如 `2026-11-26`。 |
| `title` | 是 | 字符串 | 标题。 |
| `desc` | 是 | 字符串 | 简介正文。 |
| `note` | 否 | 字符串 | 红字高亮提示，用于强调注意事项。 |
| `action` | 否 | 对象 | 卡片内跳转按钮，见下。 |
| `photos` | 否 | 字符串数组 | 图片路径列表，相对 `News/` 目录，如 `"photos/01.jpg"`。带图片的卡片默认收起，点击展开。 |

### action 对象（可选的跳转按钮）

```json
"action": { "text": "查看最终入库数据", "href": "status.html" }
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `text` | 否 | 按钮文字。省略时显示“点击查看”。 |
| `href` | 是 | 跳转地址（相对 `News/` 目录）。 |

## 新增一条动态的最小示例

在 `items` 数组里追加：

```json
{
  "date": "2026-12-01",
  "title": "冬季训练安排公布",
  "desc": "冬季训练将于下周一开始，请查看群内通知。"
}
```

保存并提交 `news.json` 即可，页面无需改动。

## 注意事项

- **JSON 语法要严格**：不能有注释，不能有多余的逗号（最后一个元素后面不能加逗号），字符串必须用双引号 `"`。
- 想换行或分段可写 `\n`（在 JSON 字符串里）。
- 图片放在 `News/photos/` 下，`photos` 里写相对路径。
- 提交前会自动校验：格式错误会导致部署失败并在 Actions 里报出具体位置，**坏数据不会被发布上线**。
